Максимальный уровень травмы
d6

Сумма уровней всех текущих травм.
Например: 1 + 1 + 2 → 4d6, уровень 2.

МЕХАНИКА

История бросков

Бросков пока нет.

    Как это работает

    Один бросок на персонажа с травмами. Количество d6 — сумма уровней всех текущих травм. Таблица — по максимальному уровню. Учитывается старший куб; две и более шестёрки означают крит.

    Без травм бросок не нужен. Здесь таблицы обычных персонажей; для Hull они другие. Результаты видны только вам; их можно скопировать для группы.

    Штрафы и травмы вносите в лист вручную. Снятие исходной травмы не отменяет полученное осложнение.

    Старший куб решает. Две шестёрки — крит.
