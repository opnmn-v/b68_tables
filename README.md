# Осложнения травм · Blades ’68 + Deep Cuts

Статическое расширение Owlbear Rodeo. Три таблицы по максимальному уровню травмы; история 50 бросков сохраняется только в браузере и очищается кнопкой. Весь интерфейс доступен без сборки и внешних зависимостей.

## GitHub Pages

1. Создайте репозиторий и загрузите **содержимое** этой папки в его корень (включая `.nojekyll`).
2. В Settings → Pages выберите Deploy from a branch → main → /(root) и сохраните.
3. После публикации добавьте в Owlbear Rodeo URL `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/manifest.json`.
4. Для дальнейших правок редактируйте `rules.mjs` (таблицы и тексты), `style.css` (оформление), `index.html` (интерфейс). Для четвёртой таблицы понадобится также обновить `evaluate()` и элементы выбора.

GitHub Pages предоставляет HTTPS. Проверьте загрузку манифеста из Owlbear после публикации: правила CORS определяет хостинг, а не файл в репозитории. Общей истории игроков пока нет.
